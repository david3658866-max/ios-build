下列项因权限、双机、感官或 adb 无法稳定驱动输入栏，需人工勾选。

---

## 1. 发送失败重发（P0）

- [x] 断网后发一条文字，出现红色失败图标
- [x] 恢复网络后点击失败图标，消息发送成功
- [x] 成功后出现「未读」或「已读」状态

> 说明：输入栏无障碍节点异常，adb 无法代发文字。

---

## 2. 退群遮罩（P0）

- [ ] 以**非群主**身份进入他人拉你进的群
- [ ] 退群后提示/遮罩为「您已不在群聊中」（或等价文案）
- [ ] 无法再发送消息

> 说明：本机测试号为群主时只能解散，不能退群；后端 `quitGroup` 仅向退群者推送 tip。

---

## 3. 解散遮罩「群聊已解散」（P0）

- [ ] 在群聊页时群主解散，或进入已解散群
- [ ] 出现「群聊已解散」遮罩（或等价）
- [ ] 无法发送

> 说明：自动化曾见到系统 tip「'xxx'解散了群聊」，遮罩文案需肉眼确认。

---

## 4. 媒体消息（P0）

- [ ] 语音：按住说话、播放
- [x] 视频：拍摄/选取发送与播放

## 5. 音视频 RTC（P0）
